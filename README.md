# RanzPinball

Pixel pinball for your thumbs, with four tables: Green Meadow, Block Quarry, Motor Rally and Deep Space.

## Install on Android
Open the **Releases** page of this repo on your phone, under "latest", and tap `RanzPinball.apk`.
Android will ask you to allow installs from your browser the first time.

Every push to `main` builds a new APK automatically (see the Actions tab).
New builds install over the old one and keep your best scores.

## Play on iPhone
Open the GitHub Pages address of this repo in Safari, tap Share, then **Add to Home Screen**.
It then opens full screen like an app and works offline.

## Editing
The whole game lives in `app/src/main/assets/index.html`. Change it, push, and a new APK and web version are built.
